# 论文表格说明

本次按所提供参考表格的排版形式制作英文表格：黑白线框、Times字体、紧凑的基因名单，以及横向多列队列表。没有改动现有论文、统计模型或组图。

## 表1：67个三来源共同显著、方向一致基因的功能归类

- 固定使用当前67基因名单：额叶bulk Meta、SEA-AD额叶星形胶质细胞局部CPS关联、ROSMAP-427前额叶星形胶质细胞gpath关联均为全基因FDR<0.05，且效应符号一致。
- 其中56个正向、11个负向。两个单核来源是连续病理指标的关联，不是AD与对照二分类logFC。
- 沿用现有六领域注释及其BP/MF优先、CC回退、最高支持数并列保留的规则，没有为了本表重新分配基因。
- 51个基因至少有一个领域归属；16个在本次现有注释中无归属，单列保留。未归属不等于没有生物学功能。
- 同一基因允许出现于多个领域，因此各领域人数不能直接相加作为独立基因总数。表中列出该领域总数及正向/负向数。
- 这是功能注释表，不是显著富集结果。每条归属的GO证据另存CSV。

## 表2：当前六脑区队列明细

- 采用20261113版当前Meta输入，及20261116版组图冻结的队列清单。总计20个GEO、28个队列×脑区贡献、17个保守来源家族。
- 额叶10、颞叶5、海马6、内嗅2、枕叶3、小脑2个贡献；同一GEO在不同脑区分别占一行。
- 表中AD与对照数为区域内聚合后的供体×脑区记录，共2041条，AD 1151、对照890；不能将跨脑区记录数称为独立供体总数。
- 根据保留样本的source_sample_ids追溯到2209条来源GSM记录，区域内合并后减少168条。缓存本身有2116行，部分GSM在进入缓存前已合并，因此缓存行数不等于原始来源GSM记录数。
- “Merged records”是保留来源GSM记录减去分析记录数，不是异常值删除数，也不能统一称为技术重复。GSE122063含技术重复/染料交换，GSE84422合并匹配GPL96与GPL97，GSE29378按供体合并CA1/CA3；具体逐队列处理保存在源数据中。
- 平台依据本地GEO元数据核对。GSE84422当前实际使用GPL96、GPL97，未把该GEO中其他未纳入的平台写进表中。
- 每个队列×脑区内，基于当前有效模型估计的全部规范化基因符号重算BH FDR；同时列出原始P<0.05、BH FDR<0.05及后者的上/下调数量。这里不是区域Meta的显著基因数。
- 家族编号和来源清单保存在CSV。相同家族编号提示来源依赖或保守合并规则，不自动代表已证明每个样本都为相同供体。
- 未从处理后矩阵推测原始探针数、测序深度或异常值删除数。

## 文件与复现

- `论文表格.tex`：XeLaTeX入口；`tex/`保存两个表的LaTeX内容。
- `论文表格_队列与67基因功能.pdf`：去除页面多余留白的最终矢量PDF，可选择和复制文字。
- `编译/paper_tables.pdf`：未经裁切的A4横向编译文件。
- `源数据/`：表格数据、GO归属证据、样本聚合对应、平台和来源家族清单。
- `核对/`：输入SHA256、数据验收和PDF验收记录。
- `预览/`：最终两页的渲染图，供排版核查。

在本目录执行：

```powershell
python 脚本/构建表格.py
xelatex -interaction=nonstopmode -halt-on-error -output-directory=编译 -jobname=paper_tables 论文表格.tex
xelatex -interaction=nonstopmode -halt-on-error -output-directory=编译 -jobname=paper_tables 论文表格.tex
python 脚本/核对与导出.py
```

仅重新编译排版不需要重跑统计，直接运行两次XeLaTeX即可。原始分析输入仍位于现有项目目录，输入清单及校验值见`核对/输入SHA256.csv`。最终PDF只裁切留白，未缩放、更改或栅格化表格内容。
